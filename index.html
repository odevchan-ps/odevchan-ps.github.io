PERSONAL AI ASSISTANT

声で話せる、
個人のためのアシスタント。

Amadeusは、運用者本人が音声や文字で会話し、予定の確認や調べものに使う日本語の個人用AIアシスタントです。

このサイトは、Amadeusの機能とデータの取扱いを説明する公開ページです。アプリ本体は、運用者が管理する非公開の接続環境で利用します。一般向けの利用登録は受け付けていません。

会話と情報の確認

音声・文字の会話を通じて、質問への回答や、許可された情報の確認を行います。音声認識と音声合成には運用者のPCを利用し、回答生成にはOpenAIのサービスを利用します。

Googleカレンダーとの連携

利用者が許可したカレンダーの予定を確認します。明示的な依頼がある場合は、設定で書込みを許可したカレンダーの予定を登録・変更・削除する機能も備えています。

接続する前に

Googleへのアクセスは、利用者の認証と許可に基づきます。取得する情報、回答生成のための外部送信、保存・接続解除については、プライバシーポリシーを確認してください。利用にあたっては利用条件も適用されます。

About Amadeus

Amadeus is a privately operated Japanese voice and text assistant for its operator's personal use. It can read authorized Google Calendar events and, on an explicit request, manage events within the configured writable calendar. The application runs in a private access environment; this public website provides application information, privacy disclosures and terms. It does not provide public registration.

See the Privacy Policy for Google data access, storage and sharing, and the Terms of Use.
